<details> <summary>B-counter</summary>

map后计数并加上是0的即可

```python title="counter"
from collections import Counter
n, m, x = map(int, input().split())
a = list(map(int, input().split()))
cnt = Counter(a)
ans = 0
for v in cnt.values():
    if v <= x:
        ans += 1
ans += (m - len(cnt))
print(ans)
```

<details> <summary>C-质因数分解</summary>

**题意：**

给你x和y求x\*y所有正因子的d\*\*d和

**题解：**

分别分解x和y，合并质因数指数，利用合并后的质因数生成所有因子，求和即可

```python title="质因数分解"
MOD = 10 ** 9 + 7
def fc(num):
    factors = {}
    d = 2
    while d * d <= num:
        if num % d == 0:
            cnt = 0
            while num % d == 0:
                num //= d
                cnt += 1
            factors[d] = factors.get(d, 0) + cnt
        d += 1 if d == 2 else 2
    if num > 1:
        factors[num] = factors.get(num, 0) + 1
    return factors
def get_factors(factors):
    res = [1]
    for p, e in factors.items():
        new = []
        for f in res:
            mul = 1
            for _ in range(e + 1):
                new.append(f * mul)
                mul *= p
        res = new
    return res
x, y = map(int, input().split())
fac_x = fc(x)
fac_y = fc(y)
for p, e in fac_y.items():
    fac_x[p] = fac_x.get(p, 0) + e
c = get_factors(fac_x)
ans = 0
for d in c:
    ans = (ans + pow(d, d, MOD)) % MOD
print(ans)
```

<details> <summary>D-差分</summary>

**题意：**

有一些区间，选择一个长度为K的区间，使得与这个区间相交的给定区间的数量最多

**题解：**

对于给定区间 $[l_i, r_i]$ 与 $[L, L+k]$ 相交，等价于：

$$
[l_i, r_i] \cap [L, L+k] \neq \varnothing
$$

即：

$$
L \le r_i \quad \text{且} \quad L+k \ge l_i
$$

即：

$$
L \in [l_i - k, r_i]
$$

因此，区间 $[l_i, r_i]$ 能与 $[L, L+k]$ 相交的 $L$ 的范围是 $[l_i - k, r_i]$

每个给定区间对应一个 $L$ 的可选区间 $[l_i - k, r_i]$。我们要求一个点 $L$ 被最多的这样的区间覆盖。

转换为**一维区间最大重叠问题**：给定若干区间 $[l_i - k, r_i]$，求一个点被覆盖的最大次数。

```python title="差分"
n, k = map(int, input().split())
g = []
for _ in range(n):
    l, r = map(int, input().split())
    g.append((l - k, 1))
    g.append((r + 1, -1))
g.sort()
cur = 0
ans = 0
for _, d in g:
    cur += d
    ans = max(ans, cur)
print(ans)
```
