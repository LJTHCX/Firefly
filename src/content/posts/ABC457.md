<details> <summary>C - 模拟</summary>

简单模拟，值得注意的是k的取值会非常大，因此直接存会RE

判断k是否大于当前序列ai在b中的总长度，如果小于，说明要找的目标在后面的序列，k-cur

否则，目标值在当前ai的重复块中，`(k-1) % L`即可求得目标

```python title="模拟"
n, k = map(int, input().split())
g = []
for _ in range(n):
    t = list(map(int, input().split()))
    g.append(t[1:])
c = list(map(int, input().split()))
for i in range(n):
    cur = len(g[i]) * c[i]
    if k > cur:
        k -= cur
    else:
        print(g[i][(k - 1) % len(g[i])])
        break
```

<details> <summary>D - 二分答案</summary>

二分答案是一中求最小的最大可能值的很有效的方法

check()函数的作用用于判断经操作后数组中的所有值能否大于mid

c++在处理本题时要注意数据的范围非常大

```python title="二分答案-py"
n, k = map(int, input().split())
a = list(map(int, input().split()))
def check(mid):
    ops = 0
    for i, x in enumerate(a):
        if x < mid:
            t = (mid - x + i) // (i + 1)
            ops += t
            if ops > k:
                return False
    return True

left = min(a) - 1
right = max(a) + k * n + 1
while left + 1 < right:
    mid = (left + right) // 2
    if check(mid):
        left = mid
    else:
        right = mid
print(left)
```

<details> <summary>G - 偏序集 + 最长上升子序列</summary>

**题意：**

我们有 $  N  $ 个事件 $(t_i, x_i)$。 &#x20;

一个机器人可以先后收集两个事件 $(t_1, x_1)$ 和 $(t_2, x_2)$（假设 $t_1 \le t_2$）当且仅当它们满足“速度约束”：

$$
|x_1 - x_2| \le t_2 - t_1
$$

也就是说，机器人在时间差内最多移动距离不超过时间差。

把这一条件改写，引入变量

$$
u = x + t, \quad v = x - t
$$

则上述条件等价于（设 $t_1 \le t_2$）：

$$
u_1 \le u_2 \quad \text{且} \quad v_1 \le v_2
$$

因此，能被同一个机器人收集的事件，在 $(u, v)$ 坐标系下，必须具有两维都不减小的偏序关系。

***

**题解：**

\*\*偏序集与 \*\*[**Dilworth 定理**](https://baike.baidu.com/item/%E7%8B%84%E5%B0%94%E6%B2%83%E6%96%AF%E5%AE%9A%E7%90%86/18900593 "Dilworth 定理")

我们把每个事件抽象成一个点 $(u, v)$，并定义偏序关系：

$$
P_1 \le P_2 \iff u_1 \le u_2 \ \text{且}\ v_1 \le v_2
$$

我们要找的是**最少的单调链**，这种链中元素全都可以被同一个机器人按照时间顺序收集

Dilworth 定理：

> **最小链划分的大小 = 最长反链的大小**

反链是集合中任意两点**不可比较**的集合，即对于任意两点 $P_1, P_2$，不能同时满足 $u_1 \le u_2 \ \text{且}\ v_1 \le v_2$。

***

在二维平面上按 $u$ 坐标排序后，反链在 $v$ 坐标上一定是**严格递减**的。 &#x20;

如果 $u_1 < u_2$ 且 $v_1 \le v_2$，那么它们就是可比较的（自然可以放在同一条链中），这就不属于反链。

因此，要构成反链，当 $u$ 递增时，$v$ 必须**严格递减**。

**最长反链的长度 = 最长严格递减子序列（**$v$\*\* 坐标）的长度\*\*​

如果 $u_1 = u_2$，那么除非 $v_1 = v_2$（不可能，因为 $(t,x)$ 不同），否则它们 $v_1 \neq v_2$。

如果 $x + t$ 相同且 $x - t$ 不同，那么它们的 $(t, x)$ 不同，但无论如何，它们的时间 $t = (u - v)/2$ 不一定相同。 &#x20;

因此，当 $u$ 相同时，先按 $v$ 降序排序，可使相同 $u$ 的点不会错误地构成一条链，因为这时 $v$ 递减，不会满足 $v_1 \le v_2$ 的要求。

由此得出求最大反链 = 最长严格递减子序列

按 $u$ 升序、$u$ 相同时按 $v$ 降序排序后，原偏序关系变成：

要两点可比，必须同时满足 $u$ 递增且 $v$ 递增（因为相同的 $u$ 我们已经按 $v$ 降序安排，它们之间无法再形成 $v$ 递增）。

于是，任何一个反链在这样的排序下就是 $v$ 严格递减的子序列。

***

```python title="反链+最长递增子序列"
import sys
import bisect
input = sys.stdin.readline
n = int(input())
a = []
for _ in range(n):
    t, x = map(int, input().split())
    a.append((x + t, x - t))
a.sort(key=lambda p: (p[0], -p[1]))
b = [p[1] for p in a]
res = []
for b in b:
    pos = bisect.bisect_left(res, b)
    if pos == len(res):
        res.append(b)
    else:
        res[pos] = b
print(len(res))
```

<details> <summary>E - 数据结构 + 二分查找</summary>

一道数据结构题，难点在于高效的存储和查询数据(暂未补)

```python title="数据结构"
import sys
from bisect import bisect_right, bisect_left
from collections import defaultdict
input = sys.stdin.readline
N, M = map(int, input().split())
by_l = [[] for _ in range(N + 1)]
by_r = [[] for _ in range(N + 1)]
cnt = defaultdict(int)
INF = 10**9
min_r_at_l = [INF] * (N + 2)
for _ in range(M):
    L, R = map(int, input().split())
    by_l[L].append(R)
    by_r[R].append(L)
    cnt[(L, R)] += 1
    if R < min_r_at_l[L]:
        min_r_at_l[L] = R

for i in range(1, N + 1):
    by_l[i].sort()
    by_r[i].sort()

suf_min_r = [INF] * (N + 3)
for i in range(N, 0, -1):
    suf_min_r[i] = min(suf_min_r[i + 1], min_r_at_l[i])

Q = int(input())
ans = []

for _ in range(Q):
    S, T = map(int, input().split())

    if cnt[(S, T)] > 0:
        ok = False
        ok |= cnt[(S, T)] >= 2
        ok |= suf_min_r[S + 1] <= T
        ok |= suf_min_r[S] <= T - 1
        print("Yes" if ok else "No")
        continue

    ok = False

    rs = by_l[S]
    pos_r = bisect_right(rs, T) - 1

    ls = by_r[T]
    pos_l = bisect_left(ls, S)

    if pos_r >= 0 and pos_l < len(ls):
        r1 = rs[pos_r]
        l2 = ls[pos_l]
        ok |= l2 <= r1 + 1
    print("Yes" if ok else "No")
```
