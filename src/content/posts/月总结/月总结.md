- 问题描述

  艺术家高砂创造了一个鱼骨架形状的物体。

  该物体由 N 肋骨和一根脊柱组成。肋骨编号为 1 到 N 。

  他想在每块 N+1 骨头上写一个字符串，满足以下所有条件。
  - 书脊上写的字符串长度是 N 。
  - 对于每根肋骨 i=1,…,N ，保持以下操作。
    - 肋条上写的字符串 i 的长度是 Ai 。
    - 写在肋骨上的字符串的第 Bi 个字符 i 等于写在书脊上的字符串的第 i 个字符。
  - N+1 骨头上写的每个字符串都是 S1,⋯,SM 之一（允许重复）。
    S1,⋯,SM 是由小写英文字母组成的字符串，并且它们都是不同的。
  对于每个 j=1,⋯,M ，回答以下问题。
  - 在满足条件的字符串写法中，有没有一种写在书脊上的字符串是 Sj ？

```python title="模拟"
def main2():
```

```python title="时间处理+输出模拟"
import datetime
def print_calendar1(year, month):
    if year < 2007:
        print("Year must be >= 2007")
        return
    # 获取该月第一天是星期几（0=星期一，6=星期日）
    first_day = datetime.date(year, month, 1).weekday()
    # 转换为星期日=0的格式（calendar 模块的格式）
    # weekday(): 0=星期一, 1=星期二, ..., 6=星期日
    # 我们需要 0=星期日, 1=星期一, ..., 6=星期六
    start_weekday = (first_day + 1) % 7
    # 获取该月的天数
    if month == 12:
        next_month = datetime.date(year + 1, 1, 1)
    else:
        next_month = datetime.date(year, month + 1, 1)
    days = (next_month - datetime.date(year, month, 1)).days
    # 输出表头
    print(f"Calendar {year}-{month:02d}")
    print("---------------------")
    print(" Su Mo Tu We Th Fr Sa")
    print("---------------------")

    # 输出日期
    # 先输出第一行的空格
    print(" " * (3 * start_weekday), end="")
    for d in range(1, days + 1):
        print(f"{d:3d}", end="")
        if (start_weekday + d) % 7 == 0:
            print()  # 换行
        else:
            print(" ", end="")
    # 如果最后一行没有换行，补一个换行
    if (start_weekday + days) % 7 != 0:
        print()
    print("---------------------")
if __name__ == "__main__":
    y, m = map(int, input().split())
    print_calendar1(y, m)
```

```python title="长度为k的严格递增子序列的个数"
def f(a,k):
    n = len(a)
    if k == 0:
        return 1
    dp = [[0]*n for _ in range(k+1)]
    for i in range(n):
        dp[1][i] = 1
    for t in range(2,k+1):
        for i in range(n):
            for j in range(i):
                if a[j] < a[i]:
                    dp[t][i] += dp[t - 1][j]
    ans = sum(dp[k][i] for i in range(n))
    return ans
n = int(input())
a = list(map(int,input().split()))
print(f(a,4))
```


### ABC452-D

**字符串S的所有连续子串中，统计出那些不包含T作为子序列的个数**

- 问题描述

  给你由小写英文字母组成的字符串 $S$ 和 $T$ 。

  在 $S$ 的非空子串 $s$ 中，请计算那些不包含 $T$ 的子串（不一定连续）。

  在这里， $S$ 的两个子串如果取自不同的位置，即使它们作为字符串是相等的，也会被区分开来。

  什么是子串？字符串 $X$ 的子串是通过删除 $X$ 开头的零个或多个字符和结尾的零个或多个字符得到的字符串。字符串 $X$ 的子串是指从 $X$ 中删除零个或多个元素，并将剩余元素按原来的顺序排列得到的字符串。

```python title="子序列自动机"
def main2():
    s = input().strip()
    t = input().strip()
    n,m = len(s),len(t)
    # 序列自动机
    # n_p[i][ch]储存的是：从s的第i个位置开始往后看，字符ch第一次出现的下标
    n_p = [[n]*26 for _ in range(n+1)] # n代表不存在
    for i in range(n-1,-1,-1):
        for j in range(26):
            n_p[i][j] = n_p[i+1][j]
        n_p[i][ord(s[i]) - ord('a')] = i

    ans = 0
    end = [n]*(n+1)
    for i in range(n-1,-1,-1):
        cur = i
        pos = True
        for ch in t:
            ch_p = ord(ch) - ord('a')
            if cur >= n or n_p[cur][ch_p] == n:
                pos = False
                break
            cur = n_p[cur][ch_p] + 1
        if pos:
            end[i] = cur - 1
        else:
            end[i] = n
        ans += (end[i] - i)
    print(ans)
if __name__ == "__main__":
    main2()
```

### 洛谷1439

**最长公共子序列→最长递增子序列**

- 问题描述

  ![](image/image_Z37nNagZp0.png)

```python title="映射+最长递增子序列"
import bisect
# 求最长递增子序列
def f(a):
    t = []
    for x in a:
        pos = bisect.bisect_left(t,x)
        if pos == len(t):
            t.append(x)
        else:
            t[pos] = x
    return t
# 求最长公共子序列
def f2(a,b):
    n = len(a)
    m = len(b)
    dp = [[0] * (m + 1) for _ in range(n+1)]
    for i in range(1,n+1):
        for j in range(1,m+1):
            if a[i-1] == b[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j],dp[i][j-1])
    return dp[n][m]
# TLE
def main():
    s = int(input())
    s1 = list(map(int,input().split()))
    s2 = list(map(int,input().split()))
    t1 = f(s1)
    t2 = f(s2)
    ans = f2(s1,s2)
    print(ans)
# 映射
def main2():
    n = int(input())
    a = list(map(int,input().split()))
    b = list(map(int,input().split()))
    pos = [0]*(n+1)
    for idx,val in enumerate(b):
        pos[val] = idx
    c = [pos[val] for val in a]
    ans = f(c)
    print(len(ans))
if __name__ == "__main__":
    main2()
```

- **那为什么需要反向传播？**

  因为第一段代码中，我们只用了 `i` 去更新 `j > i`，但 `dp[j]` 可能通过 `j-1` 得到更优值，而 `j-1` 又可能通过 `j` 得到更优值？这看起来矛盾，因为 `j > j-1`，所以 `j` 不能从 `j-1` 转移过来？

  实际上，这里的反向传播是为了**让 ****`dp[j-1]`**** 能够利用 ****`dp[j]`**** 的信息**。但按照转移方向，`j` 比 `j-1` 大，所以理论上 `j` 不可能帮助更新 `j-1`。

  **所以这个反向传播的真正作用是：**

  在第一段循环中，我们按顺序 `i=0,1,2,...` 更新。当 `i=1` 时，我们可能更新了 `dp[2]`，但 `dp[2]` 可能比 `dp[1]` 更小，而 `dp[1]` 已经在前面的 `i=0` 步中被处理过了。反向传播让后面的小值能够“传”回前面，使得下一次循环时 `dp[i]` 是最小值。

  这实际上是在模拟**动态规划中的“后效性”处理**——因为我们的转移不是按拓扑序进行的，需要多轮松弛。

### AWC40-D

[D - Crossing the Desert](https://atcoder.jp/contests/awc0040/tasks/awc0040_d "D - Crossing the Desert")

- 题目描述

  高桥正试图驾车沿一条公路穿越沙漠。高桥目前位于点 0 ，需要到达位于点 G 的绿洲。这里，点 x 代表距离起点 x 的位置。

  高桥的汽车最初装有 F 升燃料。汽车可以使用 1 升燃料行驶 1 的距离，一旦燃料耗尽就无法继续行驶。高桥只能从点 0 向点 G 单向行驶，不能折返。到达 G 点时刚好剩余 0 升燃料，仍视为到达目的地。

  在 0 点和 G 点之间有 N 个加油站。其中 i 个加油站位于 Pi 点（ 0\<Pi\<G ），可加油 Ri 升。对于每个加油站，高桥都可以选择停留或通过。如果他在加油站停留， Ri 升油量会添加到他当前的油量中。他最多只能在每个加油站停留一次。此外，如果他路过加油站，他必须加满 Ri 升油（不能加部分油）。需要注意的是，汽车油箱容量没有上限，因此无论加油后油量增加多少都没有问题。即使高桥到达加油站的时候正好是 0 升，他仍然可以在该加油站停车。

  求高桥要到达位于 G 点的绿洲至少需要停靠多少个加油站。如果无论高桥在哪个加油站停留都无法到达 G 点，则输出 −1 。

```python title="反悔贪心"
import heapq
def main():
    n,g,f = map(int,input().split())
    t = []
    for _ in range(n):
        p,r = map(int,input().split())
        t.append([p,r])
    t.append([g,0])
    t.sort(key = lambda x:x[0])
    heap = []
    cur_pos = 0
    cur_ful = f
    stop = 0
    for pos,ful in t:
        d = pos - cur_pos
        while cur_ful < d:
            if not heap:
                print(-1)
                return
            cur_ful += -heapq.heappop(heap)
            stop += 1
        cur_ful -= d
        cur_pos = pos
        heapq.heappush(heap,-ful)
    print(stop)
if __name__ == "__main__":
    main()
```


- **题解思路**

  这是一道非常经典的**贪心算法**结合**优先队列（大根堆）** 的问题，通常被称为“反悔贪心”或“时光倒流贪心”。

  这类问题的难点在于：当你到达一个加油站时，你不知道未来会不会缺油，所以很难立刻决定现在要不要加油。如果见站就加，可能会导致加油次数过多；如果不加，又可能在半路抛锚。

  核心思想：把加油站“装进后备箱”

  为了解决这个两难的选择，我们可以换一种思路：

  **不提前做决定，先往前开。沿途遇到的加油站，我们不立刻加油，而是把这些加油站的油桶“虚拟地”装进汽车后备箱。只有当汽车真的没油、马上要抛锚时，我们才从后备箱里挑出一个油量最多的油桶加进去。**

  这就相当于时光倒流，假装我们“当初在这个加油站停过车”。
  ***
  **具体算法步骤**

  **终点抽象化**

  把目的地变成最后一个加油站

  为了统一处理逻辑，我们可以把终点$G$也看作是一个加油站，它位于位置$G$，但能提供的油量为 0。这样，问题就变成了：我们能否成功开到这最后一个“加油站”。

  **按距离排序**

  整理沿途站点

  将所有加油站按照距离起点的距离$P_i$ 从小到大进行排序，保证我们是按照真实行车顺序遇到它们的。

  **模拟行车过程**

  核心贪心循环

  维护几个变量：当前位置`pos`（初始为 0）、当前油量`tank`（初始为$F$）、加油次数`ans`（初始为 0），以及一个存放备用油桶的**最大堆（优先队列）**。

  遍历排序好的加油站，对于每一个遇到的加油站：
  1. **计算距离**：计算从当前位置`pos`到这个加油站的距离$D$。
  2. **检查油量**：如果当前油量`tank`不足以开过距离$D$，我们就必须“反悔”了。不断从最大堆中取出最大的油量加到`tank`中，并且让`ans`加 1，直到`tank`大于等于$D$。
  3. **判断无解**：如果在需要加油时，发现最大堆是空的（后备箱没油桶了），说明无论怎么加油都开不到这里，直接返回`-1`。
  4. **到达并更新**：成功开到当前加油站后，扣除消耗的油量（`tank = tank - D`），将当前位置更新为该加油站位置（`pos = P_i`），然后把这个加油站的油量$R_i$ 扔进最大堆里备用。

```python title="反悔贪心"
class Solution:
    def furthestBuilding(self, heights: List[int], bricks: int, ladders: int) -> int:
        q = []
        n = len(heights)
        for i in range(n-1):
            if heights[i+1] <= heights[i]:
                continue
            d = heights[i+1] - heights[i]
            if bricks >= d:

                        bricks += top
                        ladders -= 1

                        return i
                    bricks -= d
                    heapq.heappush(q,-d)
```

  帕丽想从阿里亚那里买一块昂贵的巧克力。她有 *n* 枚硬币，其中 *i* 枚硬币的价值是 *ci* 。巧克力的价格是 *k* ，因此帕里将从她的硬币中取出一个总和等于 *k* 的子集交给阿里亚。

  看着自己的硬币，帕里想到了一个问题：把硬币给了艾莉亚后，艾莉亚能用它们创造出什么价值呢？她很嫉妒，不希望艾莉亚创造出很多价值。因此她想知道所有的值 *x* ，这样艾莉亚就能用总和为 *k* 的某个硬币子集制造出 *x* 。

  从形式上看，帕里想要知道 *x* 的值，这样就存在一个总和为 *k* 的硬币子集，这个子集的某个子集的总和为 *x* ，即存在某种支付巧克力的方式，这样艾莉亚就能用这些硬币得到总和 *x* 。

  **输入**

  第一行包含两个整数 *n* 和 *k* ( 1  ≤*n*,*k*  ≤  500 ) --分别是硬币的数量和巧克力的价格。

  下一行包含 *n* 个整数 *c*1,*c*2, ...,*c\*\*n* ( 1 ≤*c\*\*i* ≤ 500 ) - 帕里硬币的价值。

  可以保证使用这些硬币可以得到 *k* 的值。

  **输出**

  输出的第一行必须包含一个整数 *q* -合适值的个数 *x* 。然后按升序打印 *q* 整数——Arya可以为支付巧克力的某一部分的Pari硬币做出的值。

```python title="题解代码"
n,k = map(int,input().split())
c = list(map(int,input().split()))
max_sum = k
dp = [[False]*(k + 1) for _ in range(k + 1)]
dp[0][0] = True
for x in c:
    for s in range(k,-1,-1):
        for t in range(k,-1,-1):
            if dp[s][t] and s + x <= k:
                dp[s+x][t] = True
                dp[s+x][t+x] = True
ans = [t for t in range(k+1) if dp[k][t]]
print(len(ans))
print(' '.join(map(str,ans)))
```


- 思路

  **1. 题目回顾**
  - 有 n 个硬币，每个硬币有面值 c\[i]。
  - 问：对于所有可能的子集和 S，能组成 S 的子集和（即 S 的子集和）有哪些？
  - 输出所有可能的子集和（去重后）。
  ***
  **2. 二维 DP 定义**

  设 `dp[i][j]` 表示：**前 i 个硬币中，能否组成子集和为 j**？
  但这不够，因为我们要的是：**对于每个 j，能否再组成 j 的子集和**。

  所以定义：

  text

  dp\[i]\[j]\[k] = 前 i 个硬币中，能否同时组成子集和 j 和子集和 k（且 k 是 j 的子集和）？

  但这样三维会爆内存。
  ***
  **3. 标准解法（二维 DP）**

  实际上，这道题有一个经典的二维 DP 定义：

  `dp[j][k]` 表示：**当前已经考虑了部分硬币，能否组成子集和为 j，并且同时能组成子集和为 k（且 k 是 j 的子集和）**。

  更直接的说法：
  - 我们固定一个子集和 S，想知道能组成 S 的子集和有哪些。
  - 用 `dp[s][t]` 表示：能否组成一个和为 s 的集合，并且这个集合的某个子集的和为 t。
  ***
  4\. 状态转移

  对于每个硬币 `x`，从大到小更新：
  ```python 
  for s in range(max_sum, -1, -1):
      for t in range(max_sum, -1, -1):
          if dp[s][t]:
              dp[s+x][t] = True          # 新硬币加入原集合，不改变子集和 t
              dp[s+x][t+x] = True        # 新硬币加入子集和 t
  ```

  5\. 最终答案

  所有满足 `dp[s][t]` 为 True 的 t 都是答案（t 可以等于 s，表示整个集合本身）。

## 前缀和/差分

### AWC42-D-**板子**\*

**给定一个由 **$N$** 个元素组成的序列，求总和是的 **$K$** 倍的连续子序列的总数**

任意两个相同余数的前缀和位置，都对应一个和为 k 倍数的子段。

- 问题描述

  高桥有一个盒子，里面装着排成一排的 $N$ 糖果。左边第 $i$ 个糖果的重量是 $A  i$ 克。

  高桥想从这个盒子里连续选择一颗或多颗糖果，把它们装进袋子里，然后把它们作为礼物送给他的 $K$ 朋友。由于他想将糖果按重量平均分配给所有朋友，因此所选糖果的总重量必须是 $K$ 克的倍数。

  找出选择一种或多种连续糖果的方法数，使得所选糖果的总重量为 $K$ 的倍数。请注意，如果所选糖果的范围不同（即起始位置或结束位置不同），即使总重量相同，它们也会被视为不同的选择。

```python title="前缀和+组合数学"
from collections import Counter
import math
n,k = map(int,input().split())
a = list(map(int,input().split()))
cur = 0
s = Counter()
s[0] = 1
pre = [0]*(n+1)
for i,x in enumerate(a):
    pre[i+1] = (pre[i] + x)%k
    s[pre[i+1]] += 1
ans = 0
for c in s.values():
    if c >= 2:
        ans += math.comb(c,2)
print(ans)
```


- 题解思路

  给定一个由 $N$ 个元素组成的序列，求总和是 $K$ 倍的连续子序列的总数。

  选择连续子序列的方法有 $O(N^2)$ 种，其中我们选择左端点 $i$ 和右端点 $j$ 。如果我们计算每个子序列的和，并检查 $K$ 的可分割性，那么整体时间复杂度为 $O(N^3)$ ，即使使用前缀和也是 $O(N^2)$ 。考虑到 $N \leq 2 \times 10^5$ 的限制，计算速度太慢，无法满足时间限制。

  **前缀和与余数性质**

  为了有效处理连续子序列求和，我们使用前缀求和。假设 $S_i$ 是前 $i$ 项的总权重。那么从项目 $i+1$ 到项目 $j$ 的和可以表示为 $S_j - S_i$ 。

  这个和是 $K$ 的倍数的条件可以写成 $(S_j - S_i) \equiv 0 \pmod K$ 重排 $S_j \equiv S_i \pmod K$&#x20;

  高效计数

  如果有 $c$ 个指数具有相同的前缀和余数，那么从中选择 2 个指数的次数为 ${}_c\mathrm{C}_2 = \frac{c(c-1)}{2}$ 。通过对所有余数（从 $0$ 到 $K-1$ ）求和，我们可以计算出 $O(N)$ 中的答案。

  算法
  1. **计算前缀和**：从头开始扫描数组，计算当前前缀和除以 $K$ 的余数。
  2. **记录每个余数的频率**：使用哈希图（在 Python 中为 `collections.Counter` 或字典）来计算每个余数出现的次数。
     - 注意：您必须将初始前缀和 0（尚未选择任何项目的状态）包含在计数中。
  3. **计算组合**：对于频率为 $c$ 的每个余数，计算 $\frac{c(c-1)}{2}$ 并将所有这些值相加。

```python title="前后缀分解-一维"
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        """
        pre[i]:从nums[0] 到 nums[i-1]的乘积
        suf[i]:从nums[i+1] 到 nums[n-1]的乘积
        ans[i] = pre[i]*suf[i]

        n = len(nums)
        pre = [1] * n
        for i in range(1,n):
            pre[i] = pre[i-1]*nums[i-1]
        suf = [1] * n
        for i in range(n-2,-1,-1):
            suf[i] = suf[i+1] * nums[i+1]
        return [p*s for p,s in zip(pre,suf)]
```

```python title="二位前缀和"
class Solution:
    def matrixBlockSum(self, grid: List[List[int]], k: int) -> List[List[int]]:
        n,m = len(grid),len(grid[0])
        pre = [[0]*(m+1) for _ in range(n+1)]
        for i,row in enumerate(grid):
            for j,x in enumerate(row):
                pre[i+1][j+1] = pre[i+1][j] + pre[i][j+1] - pre[i][j] + x
        ans = [[0]*(m) for _ in range(n)]
        for i in range(n):
            for j in range(m):
                x1 = max(0,i - k)
                y1 = max(0,j - k)
                x2 = min(n-1,i + k)
                y2 = min(m-1,j + k)
                ans[i][j] = pre[x2+1][y2+1] - pre[x2+1][y1] - pre[x1][y2+1] + pre[x1][y1]
        return ans
```


## 二分+双指针/滑动窗口

### AWC41-B

- 题目描述

  问题陈述

  高桥正在做一项在排成一排的 $M$ 方块上滚球的实验。

  这些方块的编号从 $1$ 到 $M$ ，其中方块 $1$ 位于最高位置，方块 $M$ 位于最低位置。每对相邻的方块之间有一个台阶，方块 $i$ （ $1 \leq i \leq M - 1$ ）和方块 $i + 1$ 之间的台阶有一个权重阈值 $W_i$ ，决定球是否可以通过。重量至少为 $W_i$ 的球可以滚过此台阶到达正方形 $i+1$ ，但重量小于 $W_i$ 的球无法通过此台阶并停在那里。

  高桥使用 $N$ 球进行实验。球 $j$ ( $1 \leq j \leq N$ ) 的重量为 $B_j$ 。对于每个球，独立于其他球进行以下实验。

  当高桥将球 $j$ 放在正方形 $1$ 上时，球按照以下规则滚动：
  1. 令 $p$ 为球的当前方格。最初， $p = 1$ 。
  2. 如果 $p<M$ 和 $B_j \geq W_p$ ，则球滚动到正方形 $p + 1$ （将 $p$ 更新为 $p + 1$ ）。只要满足条件，就重复此步骤。
  3. 如果 $p = M$ 或 $B_j < W_p$ ，则球停在方格 $p$ 。
     对于每个球，确定它最终停止的方格数。

```python title="前缀最大值+二分查找"
import bisect
def solve():
    n, m = map(int, input().split())
    w = list(map(int, input().split()))
    b = list(map(int, input().split()))
    pre = [0] * (m - 1)
    pre[0] = w[0]
    for i in range(1, m - 1):
        pre[i] = max(pre[i - 1], w[i])
    for t in b:
        ans = bisect.bisect_right(pre,t)
        print(ans+1)
if __name__ == "__main__":
    solve()
```


- 题解思路

  3\\.优化思路：前缀最大二分查找

  为了有效地找到每个球可以走多远，我们使用以下属性： - 克服步骤的条件是 $B_j \geq \max(W_1, \dots, W_k)$ 。 - 定义 $P_k = \max(W_1, \dots, W_k)$ ，数组 $P$ 满足 $P_1 \leq P_2 \leq \dots \leq P_{M-1}$ ，使其**非递减**（值永远不会递减）。

  当数组排序（单调非递减）时，我们可以使用**二分查找**来快速找到满足特定条件的边界。具体来说，通过使用二分搜索找到最大的 $k$ ，使得 $P_k \leq B_j$ ，我们获得“可以克服的步数”。

  算法
  1. **计算前缀最大值**：从步长权重数组 $W$ 中，创建前缀最大值数组 $P$ 。设置 $P_i = \max(W_1, W_2, \dots, W_i)$ 。
  2. **对每个球进行二分搜索**：对于每个球的重量 $B_j$ ，使用二分搜索（例如 Python 中的 `bisect_right`）来查找数组 $P$ 中小于或等于 $B_j$ 的值延伸了多远。
  3. **确定停止单元格**：如果克服的步数为 $k$ ，则小球停止的单元格编号为 $k+1$ 。
     具体示例
  - 步重 $W = [3, 5, 2, 8]$
  - 前缀最大值 $P = [3, 5, 5, 8]$
  - 对于重量为 $B_j = 6$ 的球：
    - $P$ 中的元素为 $\leq 6$ 为 $3, 5, 5$ — 总共为 $3$ 。
    - 这意味着可以克服 $3$ 步，因此球会停在单元格 $3 + 1 = 4$ 处。

- 题目描述

  对于非负整数，异或和 ≤ 和，等号成立当且仅当**没有进位**，即所有数的二进制表示中，没有两个数在某一位同时为 1（即每个位最多出现一次）。

  换句话说，区间内所有数的二进制表示是**互不相交**的（每个位最多出现一次）。

  所以：
  $$
  \text{xor}(l, r) < \text{sum}(l, r) \iff \text{区间内存在至少两个数在某一位同时为 1}
  $$
  ***
  3\. 问题转化

  美丽区间 = 存在至少两个数在某个二进制位同时为 1 的区间。

  不美丽区间 = 区间内所有数的二进制位互不相交。
  ***
  4\. 计数方法

  总区间数 = $  \frac{n(n+1)}{2}  $。

  我们可以求**不美丽区间**的个数，然后用总数减去。

  不美丽区间：区间内所有数的位或（bitwise OR）等于它们的和（即没有进位）。
  ***
  5\. 如何求不美丽区间？

  由于 $  a_i < 2^{16}  $，只有 16 个二进制位。 &#x20;

  不美丽区间的条件是：对于每个位，区间内最多只有一个数在该位为 1。

  我们可以用**滑动窗口**（双指针）来统计以每个右端点结尾的不美丽区间个数。

  维护一个窗口 $[l, r]$，使得窗口内所有数的位或等于它们的和（即无冲突）。 &#x20;

  当加入新数 $  a[r]  $ 时，如果它和当前窗口的位或有冲突（即 `(bits & a[r]) != 0`），则移动左指针直到无冲突。

  然后以 $  r  $ 结尾的不美丽区间数为 `r - l + 1`。
  ***
  6\. 算法步骤
  1. 初始化 `left = 0`, `bits = 0`, `ans = 0`。
  2. 遍历 `right` 从 0 到 n-1：
     - 当 `(bits & a[right]) != 0` 时，移动 `left`，并从 `bits` 中移除 `a[left]`（`bits ^= a[left]`），直到无冲突。
     - 将 `a[right]` 加入 `bits`（`bits |= a[right]`）。
     - 以 `right` 结尾的不美丽区间数 = `right - left + 1`，累加到 `ans`。
  3. 美丽区间数 = 总区间数 - `ans`。
  ***

## 数学-GCD

### 蓝桥寒假训练营2D1-T5

- 问题描述

  ![](image/image_Cs9tKM4c9I.png)

```python title="gcd"
    g = math.gcd(g,x)
```

- 题解思路
  ***
  **1. 问题本质**

  我们有若干不同的正整数，每次可以取两个数 $x, y$，产生新数 $|x - y|$，且不能有重复的数。问最终能得到的数的总和最大是多少。

  这本质上是一个**生成所有 gcd 的倍数**的过程。
  ***
  **2. 辗转相减法与欧几里得算法**

  回顾：欧几里得算法（辗转相除法）用于求两个数的最大公约数（gcd）。 &#x20;

  它基于一个关键性质：
  $$
  \gcd(a, b) = \gcd(a - b, b) \quad (a > b)
  $$
  也就是说，通过反复做减法，我们可以得到 gcd。

  例如：$  \gcd(12, 8)  $：
  - 12 - 8 = 4 → 得到 4
  - 8 - 4 = 4 → 得到 4（重复，忽略）
  - 最终得到 4，即 gcd。
  ***
  **3. 从 gcd 到所有倍数**

  一旦我们得到了 gcd = $d$，那么通过减法我们可以得到 $d$ 的任意倍数（不超过最大值）。

  例如：有 $d$ 和某个数 $k d$（$k > 1$），那么：
  - $k d - d = (k-1)d$ → 得到 $(k-1)d$
  - 继续，我们可以得到所有 $d, 2d, 3d, \dots, kd$。
    这个过程类似于“用减法实现加法”：
  - 从 $d$ 和 $2d$ 得到 $d$（已有）
  - 从 $2d$ 和 $d$ 得到 $d$（已有）
  - 但如何得到 $3d$？ &#x20;

    实际上，如果我们有 $2d$ 和 $d$，我们只能得到 $d$，不能得到 $3d$。 &#x20;

    所以我们需要一个更大的数作为“种子”。 &#x20;

    初始集合中最大的数 $M$ 就是最大的种子，我们可以从 $M$ 和 $d$ 得到 $M-d$，然后从 $M$ 和 $M-d$ 得到 $d$，再从 $M$ 和 $d$ 得到 $M-d$，这样反复，实际上我们无法得到大于 $M$ 的数，但可以得到所有小于等于 $M$ 的 $d$ 的倍数吗？

    其实，经典结论是：通过反复取差，可以得到的数集是初始数集的 **整数线性组合** 的集合，即所有形如 $c_1 a_1 + c_2 a_2 + \dots + c_n a_n$ 的整数（$c_i$ 为任意整数，可正可负）。 &#x20;

    由于我们可以取差（相当于加负数），实际上我们得到的数集就是所有数的整数线性组合，即它们的 **最大公约数** 的倍数。

    因此，最终能得到的数就是所有 $d$ 的倍数，且不超过初始最大值（因为差不会变大，只会变小）。
  ***
  **4. 为什么不能超过最大值？**

  因为每次操作产生的差一定小于较大的那个数，所以所有新数都小于当前最大值。因此，最终集合中所有数都不超过初始最大值。
  ***
  **5. 最终集合**

  因此，从初始数集出发，通过反复取差，最终能得到且仅能得到所有不超过 $\max(a)$ 的 $d$ 的倍数。 &#x20;

  其中 $d = \gcd(a_1, a_2, \dots, a_n)$。

  所以最大可能的总和就是：
  $$
  S = d + 2d + 3d + \dots + \left\lfloor \frac{\max(a)}{d} \right\rfloor \cdot d
  $$
  即
  $$
  S = d \cdot \frac{t(t+1)}{2}, \quad \text{其中 } t = \left\lfloor \frac{\max(a)}{d} \right\rfloor
  $$
  ***
  **6. 数学证明概要**
  1. 任何两个数的差都是它们的整数线性组合。
  2. 所有数的整数线性组合的集合就是 $d\mathbb{Z}$（$d$ 的整数倍）。
  3. 由于操作只能产生小于当前最大值的数，所以最终得到的数都在 $1$ 到 $\max(a)$ 之间。
  4. 因此，最终得到的数就是所有不超过 $\max(a)$ 的 $d$ 的倍数。
  5. 能否得到所有？可以：通过辗转相减法得到 $d$，然后从 $d$ 和某个 $k d$ 得到 $(k-1)d$，从而递归得到所有。
  ***
  **7. 示例**

  初始：$[4, 8, 10]$
  - $\gcd = 2$
  - 最大数 = 10
  - $t = 10/2 = 5$
  - 倍数：2,4,6,8,10
  - 总和 = $2 \times (5 \times 6 / 2) = 30$
  ***
  **8. 结论**

  这道题的核心数学背景是：
  - **欧几里得算法**：辗转相减得到 gcd。
  - **整数线性组合**：所有数的整数线性组合就是 gcd 的倍数。
  - **生成所有倍数**：通过反复取差，可以得到所有不超过最大值的 gcd 倍数。
    最终答案 = $\gcd \times \frac{t(t+1)}{2}$，其中 $t = \lfloor \max / \gcd \rfloor$。

## 数学-博弈

### CF-1033

- 问题描述

  经过漫长的一天，爱丽丝和鲍勃决定玩一个小游戏。游戏棋盘由 n 个单元格组成，这些单元格排成一条直线，编号从 1 到 n ，其中每个单元格包含的数字 ai 介于 1 和 n 之间。此外，没有两个单元格包含相同的数字。

  在其中一个单元格中放置一个令牌。两人轮流在棋盘上移动令牌，爱丽丝先移动。只有满足以下两个条件，当前玩家才能从 i 单元移动到 j 单元：
  - 新格 j 中的数字必须严格大于旧格 i 中的数字（即 aj>ai ），并且
  - 令牌在这一轮中移动的距离必须是旧格中数字的倍数（即 |i−j| mod ai=0 ）。
    无法移动的一方输。对于每种可能的起始位置，如果双方都以最佳方式下棋，那么谁会赢呢？可以证明博弈总是有限的，即总有一方的策略是赢的。

```python title="博弈+数学+DP"
n = int(input())
a = list(map(int,input().split()))
pos = [0]*(n+1)
for i,val in enumerate(a):
    pos[val] = i
dp = [False]*n
for val in range(n,0,-1):
    # |i - j| % a[i] == 0 等价于 j = i ± k * a[i]
    i = pos[val]
    st = val
    for j in range(i+st,n,st):
        if a[j] > val and not dp[j]:
            dp[i] = True
            break
    for j in range(i - st,-1,-st):
        if a[j] > val and not dp[j]:
            dp[i] = True
            break
print(''.join("A" if dp[i] else 'B' for i in range(n)))
```


- 题解思路
  - 有一个排列 `a[1..n]`（1 到 n 的每个数恰好出现一次）。
  - 从位置 `i` 可以移动到 `j`，当且仅当：
    1. `a[j] > a[i]`（数值更大）
    2. `|i - j|` 能被 `a[i]` 整除。
  - 无法移动的人输。
  - 问：对于每个起始位置，先手是否必胜？
  ***
  2\. 思路
  - 定义 `dp[i]` 表示从位置 `i` 出发，当前玩家是否必胜（`True` 表示先手赢）。
  - 如果从 `i` 出发能走到**任意一个必败态**，则 `dp[i] = True`。
  - 否则 `dp[i] = False`。
  ***
  4\. 关键点解释

  ① 为什么按数值从大到小处理？
  - 因为只能移动到数值更大的位置，所以数值大的位置是“终点”，没有出边。
  - 先处理数值大的位置，得到它们的胜负态，然后数值小的位置才能正确转移。
    ② 为什么只检查步长为 `val` 的位置？
  - 条件 `|i - j| % a[i] == 0` 等价于 `j = i ± k * a[i]`（k 为正整数）。
  - 所以我们只需要检查 `i + val`、`i + 2*val`、... 和 `i - val`、`i - 2*val`、... 这些位置。
    ③ 为什么检查到第一个必败态就停止？
  - 因为只要有一个后继是必败态，当前玩家就可以选择走到那里，从而获胜。
  - 所以一旦找到，立即标记 `dp[i] = True` 并跳出循环。
    ④ 为什么先向右再向左？
  - 顺序不重要，只要检查完所有步长的位置即可。先右后左只是习惯。
  ***
  5\. 示例模拟

  输入：
  ```text 
  5
  3 1 2 5 4
  ```

  - `a = [3,1,2,5,4]`
  - `pos`：值 1→1, 2→2, 3→0, 4→4, 5→3
    处理 `val=5`（位置 3）：
  - 向右：4,5... 越界
  - 向左：2,1,0... 检查位置 2（a\[2]=2<5 不满足 a\[j]>5）... 没有
  - `dp[3]=False`
    处理 `val=4`（位置 4）：
  - 向右：越界
  - 向左：位置 0（a\[0]=3<4 不满足），位置 -4 越界
  - `dp[4]=False`
    处理 `val=3`（位置 0）：
  - 向右：位置 3（a\[3]=5>3 且 `dp[3]=False`）→ 找到必败态 → `dp[0]=True`
    处理 `val=2`（位置 2）：
  - 向右：位置 4（a\[4]=4>2 且 `dp[4]=False`）→ `dp[2]=True`
    处理 `val=1`（位置 1）：
  - 向右：位置 2（a\[2]=2>1 且 `dp[2]=True` → 必胜态，不是我们想要的）
  - 继续：位置 3（a\[3]=5>1 且 `dp[3]=False`）→ 找到必败态 → `dp[1]=True`？等等，这里发现位置 3 是必败态，所以 `dp[1]=True`。但之前我们以为 1 是必败？需要重新检查。
    实际上，在向右检查时，我们找到第一个满足条件的就 break，所以位置 1 会先检查到位置 2（dp\[2]=True），此时条件成立，但 `dp[2]` 是 True，不是 False，所以不会触发 `dp[1]=True`。继续检查位置 3（dp\[3]=False），满足条件，所以 `dp[1]=True`。因此最终 `dp[1]=True`。
  最终 dp = \[True, True, True, False, False] &#x20;

  输出：`A A A B B`，即 `AAABB`。
  ***
  7\. 总结
  - 核心：**按数值从大到小 DP** + **步长跳跃检查**。
  - 状态转移：`dp[i] = True` 当且仅当存在一个可达位置 `j` 且 `dp[j] = False`。
  - 输出 `'A'` 表示先手赢，`'B'` 表示先手输。

```python title="组合数学"
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD
    invfact = [1] * (n + 1)
    invfact[n] = modinv(fact[n])
    for i in range(n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD
    ans = fact[n] * invfact[K] % MOD * invfact[n - K] % MOD
    print(ans)
if __name__ == '__main__':
    main5()
```

```python title="逆元解法-正解"
MOD = 10 ** 9 + 7
def modinv(x):
    return pow(x, MOD - 2, MOD)
def solve():
    n, m = map(int, input().split())
    max_k = n - m
    if max_k < 1:
        print(0)
        return
    ## 预处理阶乘到 n+1
    fact = [1] * (n + 5)
    for i in range(2, n + 5):
        fact[i] = fact[i - 1] * i % MOD
    inv_fact = [1] * (n + 5)
    inv_fact[n + 4] = modinv(fact[n + 4])
    for i in range(n + 4, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD
    def C(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * inv_fact[b] % MOD * inv_fact[a - b] % MOD
    ##
    ans = 0
    for k in range(1, max_k + 1):
        ans = (ans + C(n - k + 1, k)) % MOD
    print(ans)
if __name__ == "__main__":
    solve()
```


- 题解思路

  好的，我们先一步步分析。
  ***
  1\. 题意理解
  - 有 `n` 天，每天可以选择“参加训练”或“休息”。
  - 规则：
    1. 不能连续休息两天及以上（即休息的天数不能相邻）。
    2. 至少参加 `m` 次训练（即休息的天数 ≤ `n - m`）。
  - 求满足条件的方案数（对 `1e9+7` 取模）。
  ***
  2\. 转化

  设 `k` 为休息的天数，则 `0 ≤ k ≤ n - m`（因为至少参加 m 次，所以休息最多 n-m 天）。

  并且休息的天数不能相邻。

  问题转化为：在 `n` 天中选 `k` 个位置作为休息，要求这些位置两两不相邻，求方案数。
  ***
  3\. 经典组合数学公式

  在 `n` 天中选 `k` 个不相邻的休息日的方案数为：
  $$
  \binom{n - k + 1}{k}
  $$
  解释：先放 `n - k` 个“参加”的天，它们之间有 `n - k + 1` 个空隙（包括两端），从这些空隙中选 `k` 个放入“休息”天，每个空隙最多放一个，即可保证不相邻。
  ***
  4\. 总方案数

  因此，总方案数为：
  $$
  \sum_{k=1}^{n-m} \binom{n - k + 1}{k}
  $$
  ***
  5\. 计算

  由于 `n ≤ 1e5`，可以直接用组合数公式计算，预处理阶乘和逆元，然后累加。

## 数学-位运算

- 问题描述

  ![](image/image_7jJBLScMwd.png)
- 题解思路

  这道题是一道非常经典的**位运算（Bitwise Operations）** 贪心题。核心在于理解“按位或（OR，`|`）”运算的单调递增性质：**参与“或”运算的数字越多，结果的二进制位上的 **$1$** 只会多不会少，数值也就可能越大**。

  下面为你详细梳理这道题的推导思路和极简的代码实现。

  我们的目标是从 $1$ 到 $n$ 中选出 $k$ 个不同的数，使得它们的按位或结果最大。

  根据可选的数量 $k$，我们可以将问题分为两种情况：

  **情况一：**$k = 1$

  只能选择 $1$ 个积木。为了让价值最大，显然我们直接选择编号最大的那一个即可。
  - \*\*最大价值 = \*\*$n$**情况二：**$k \ge 2$
  当我们可以选择 $2$ 个或更多积木时，情况就变得非常巧妙了。
  1. **寻找理论上限**：

     假设 $n$ 的二进制最高位处于第 $p$ 位（例如 $n=10$ 的二进制是 `1010`，最高位在第 $3$ 位，对应的权值是 $2^3 = 8$）。

     因为我们只能从 $\le n$ 的数字里选，所有可选数字都不会触及第 $p+1$ 位。因此，我们能达到的**绝对理论最大值**，就是把第 $p$ 位及以下的所有低位全部填满 $1$。

     这个全部是 $1$ 的数等于 $2^{p+1} - 1$。
  2. **证明一定能达到理论上限**：

     只要 $k \ge 2$，我们能否一定凑出这个全 $1$ 的数呢？答案是**一定能**。
     - 由于 $n$ 的最高位权值是 $2^p$，说明 $2^p \le n$。我们一定可以选择 $2^p$（它的二进制形式为 `100...0`）。
     - 因为 $n \ge 2^p$，且 $k \ge 2$ 意味着 $n \ge 2$，所以 $2^p - 1 \ge 1$。我们一定可以选择 $2^p - 1$（它的二进制形式为 `011...1`）。
     - 这两个数不仅都在 $[1, n]$ 范围内，而且肯定是不同的两个数。
     - 将它们进行按位或运算：$2^p \mid (2^p - 1) = 2^{p+1} - 1$。完美凑成了理论最大值！
       如果 $k > 2$，剩下的 $k-2$ 个数我们可以从剩下的积木中随便挑，因为“按位或”运算并不会抹去已经变成 $1$ 的位，结果将始终保持在 $2^{p+1} - 1$。

```python title="位运算"
for _ in range(int(input())):
    n,k = map(int,input().split())
    if k == 1:
        print(n)
    else:
        p = n.bit_length()
        print((1 << p) - 1)
```
